# شركة إير كول للمكيفات بجدة (Air Cool Jeddah HVAC Website)

موقع تجاري متكامل عالي التحويل ومتوافق هندسياً مع متطلبات محركات البحث (Technical SEO)، وتجربة المستخدم السريعة (Core Web Vitals)، ومصمم بالكامل للغة العربية وباتجاه RTL.

---

## 1. التقنيات المستخدمة (Tech Stack)
- **الهيكل والبنية:** HTML5 دلالي (Semantic HTML5) مع وسوم ARIA لتحقيق سهولة الوصول.
- **التنسيق والتصميم:** Tailwind CSS v3 (بناء محلي باستخدام PostCSS ومترجم إلى `assets/css/style.css` المنقى والمضغوط، دون الاعتماد على CDN).
- **التفاعل والوظائف:** Vanilla JavaScript أصلي وخفيف لإدارة القوائم المتجاوبة، الأكورديون، والتحقق المتقدم من أرقام الهواتف السعودية ونماذج الحجز.
- **الخطوط:** Cairo وTajawal من Google Fonts مع خاصية `font-display: swap` وبدائل نظامية لتقليل وميض الخطوط (FOIT).
- **الهوية البصرية:** نظام ألوان يعكس التبريد والمصداقية:
  - الأزرق الداكن الأساسي: `#102A43`
  - الأزرق الملكي: `#1677D2`
  - السماوي المنعش: `#35C6F4`
  - البرتقالي المميز لأزرار الإجراء (CTA): `#F59E0B`
  - الأبيض والرمادي الفاتح للخلفيات: `#F4F8FC`

## 3. التشغيل والتطوير محلياً (Development Commands)

### تثبيت التبعيات:
```bash
npm install
```

### إعادة بناء ملف CSS للإنتاج (Minified):
```bash
npm run build:css
```

### وضع المراقبة التلقائية أثناء التعديل (Watch Mode):
```bash
npm run watch:css
```

## 5. خطوات الرفع على الاستضافة (Deployment Steps)

1. **استضافة Apache / cPanel / Shared Hosting:**
   - ارفع كافة محتويات المجلد مباشرة إلى مجلد `public_html`.
   - ملف `.htaccess` يتولى تلقائياً تفعيل HTTPS، وضغط Gzip للملفات، والتخزين المؤقت في متصفح الزائر (Browser Caching)، وتحويل الروابط النظيفة.
2. **استضافة Nginx / VPS:**
   - إذا كنت تستخدم Nginx، قم بنقل قواعد الـ Gzip وقواعد إعادة التوجيه إلى ملف `nginx.conf` وتفعيل شهادة Let's Encrypt مجاناً عبر Certbot.
3. **الربط مع Google Search Console:**
   - بعد رفع الموقع، افتح Google Search Console وأضف النطاق.
   - أرسل رابط خريطة الموقع: `https://aircoolsa.com/sitemap.xml`.
