سياسة الخصوصية وحماية البيانات

تلتزم إير كول بحماية خصوصية بيانات عملائها وزوار موقعها الإلكتروني aircoolsa.com. توضح هذه الوثيقة نوعية المعلومات التي نجمعها وكيفية استخدامها لحجز خدمات صيانة وتنظيف وتركيب المكيفات في مدينة جدة.

1. البيانات التي نجمعها

عند تقديم طلب خدمة أو حجز فني تكييف عبر الموقع أو نموذج التواصل، نطلب البيانات التالية فقط لغرض تقديم الخدمة:

  • الاسم للتواصل والتعريف.
  • رقم الجوال لتأكيد الموعد وإرسال تفاصيل الخدمة عبر الاتصال أو واتساب.
  • الحي أو المنطقة السكنية في جدة لتوجيه الفني إلى موقع العميل.
  • نوع الخدمة المطلوبة وملاحظات العطل أو المشكلة الفنية.

2. الغرض من جمع البيانات

تُستخدم البيانات فقط لجدولة مواعيد الفحص والصيانة، وتزويد العميل بالتكلفة التقديرية قبل العمل، وإجراء المتابعة الفنية للضمان. لا نقوم ببيع أو تأجير أو مشاركة أي بيانات شخصية مع أي جهات خارجية غير معنية بتنفيذ الخدمة.

3. أمان وحفظ المعلومات

نطبق معايير تقنية مشددة لحماية سرية البيانات والاتصالات عبر التشفير (HTTPS). ولا يتم تخزين بيانات بطاقات بنكية أو معلومات مالية حساسة على الموقع.

4. حقوق العميل والتواصل

يحق للعميل في أي وقت طلب تعديل أو حذف بيانات التواصل الخاصة به من سجلات الخدمة عبر مراسلتنا مباشرة على رقم الهاتف 0533553620 أو عبر واتساب.
